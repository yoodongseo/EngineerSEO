# knowledge_base 운영 가이드

이 디렉터리는 AnsibleHarness AI/RAG v1이 참조하는 **공식 큐레이션 말뭉치**의 루트입니다.

## 목적

- 이 저장소의 AI 기능은 `knowledge_base/` 아래에 **의도적으로 선별해 넣은 문서만** 근거로 사용합니다.
- 저장소 전체를 자동 스캔하거나, `docs/`, `backend/`, `frontend/`, `Request.md` 같은 다른 경로를 자동 수집하지 않습니다.

## 하위 디렉터리

- `ansible/`: Ansible 플레이북, role, task, 인벤토리 운영 문서
- `python/`: Python 스타일 가이드, 구현 규칙, 코드 품질 문서

## 큐레이션 원칙

- v1에서는 **엄선된 파일만 수동으로 추가**합니다.
- 초안, 임시 메모, 개인 실험 파일, 근거가 불명확한 자료는 넣지 않습니다.
- 중복 문서보다는 최신 기준 문서를 우선 유지합니다.
- 실제 답변 근거로 사용되므로 출처가 분명하고 유지보수 가능한 자료만 보관합니다.

## v1 지원 파일 형식

다음 확장자만 인덱싱 대상으로 취급합니다.

- `.txt`
- `.md`
- `.html`
- `.yml`
- `.yaml`
- `.py`

지원하지 않는 형식은 v1에서 수집하지 않습니다.
