# 한국도로공사 자동화 구현

Ansible 플레이북과 일부 Python 보조 코드를 활용해 서버 운영 작업, 자원 점검, 비밀번호 변경, 미들웨어와 DB 관리, 취약점 및 포트 점검, 리포트 자동화를 구성한 코드입니다.

## 주요 구현 영역

| 영역 | 내용 | 코드 |
| --- | --- | --- |
| 비밀번호 변경 | Linux, Windows, AIX 대상 비밀번호 변경 작업 | [비밀번호변경](비밀번호변경/) |
| DB 관리 | DB 상태 변경 및 종료 작업 | [DB_관리](DB_관리/) |
| 리포트 자동화 | 결과 데이터 처리와 리포트 생성 작업 | [리포트_자동화](리포트_자동화/) |
| 명령 실행 | 대상 장비 명령 실행 플레이북 | [명령실행](명령실행/) |
| 서버 자원점검 | Linux, UNIX, Windows 자원 정보 수집 | [서버_자원점검](서버_자원점검/) |
| 포트 점검 | Linux와 Windows 대상 포트 상태 점검 및 결과 저장 | [포트_점검](포트_점검/) |
| 미들웨어 관리 | Tomcat과 WebToB 시작·종료 작업 | [미들웨어_관리](미들웨어_관리/) |
| 서비스 라이선스 관리 | JEUS와 WebToB 라이선스 변경 절차 | [서비스_라이선스관리](서비스_라이선스관리/) |
| 취약점점검 | OS, Oracle, JEUS, WebToB 대상 취약점점검 연계 | [취약점점검](취약점점검/) |

## 구조

```text
한국도로공사/
├── 비밀번호변경/
│   ├── aix/
│   ├── linux/
│   └── windows/
├── DB_관리/
├── 리포트_자동화/
├── 명령실행/
├── 미들웨어_관리/
├── 서버_자원점검/
├── 서비스_라이선스관리/
├── 취약점점검/
└── 포트_점검/
```
