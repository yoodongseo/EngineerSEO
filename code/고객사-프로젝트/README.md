# 고객사 프로젝트 코드

고객사별 실제 자동화 구현을 익명화해 정리한 코드입니다.

각 고객사 폴더는 사업 단계와 자동화 기능을 기준으로 구성합니다. 원본 작업 폴더명, 테스트 폴더, 결과 파일, 고객사 내부 정보는 포함하지 않습니다.

- 고객사별 실제 구현: `고객사-프로젝트/<고객사>/`
- 공통 실행·필터·저장 모듈: `../공통-모듈/`
- 별도 관리 코드: `../ansible-harness/`, 저장소 밖의 `prompt`, `result_lab`

프로젝트별 포트폴리오 설명과 Notion 반영은 코드 근거 확인 및 사용자 검토가 끝난 뒤 진행합니다.
