# K뱅크 서버 점검 자동화

K뱅크 인프라 자동화 프로젝트에서 구현한 서버 일일점검 및 보안점검 관련 일부 코드입니다.

전체 프로젝트에서는 S/W 배포·설치, 서버 일일점검, 시스템 설정 정보수집, 보고 자동화 및 레포팅, 서버 보안점검을 구축했으며, 공개 저장소에는 보안 정책상 반출 가능한 점검 자동화 코드만 선별해 정리했습니다.

## 주요 구현

- 서버 일일점검 및 보안점검 자동화
- 점검 항목별 명령어와 기준값 분리
- 항목별 Filter를 이용한 실행 결과 가공
- 점검 결과 판정 및 보고 데이터 처리

## 구현 방식

점검 명령어와 기준값을 변수로 분리하고, 점검 항목에 따라 필요한 Filter를 연결해 결과를 가공하도록 구성했습니다.

CPU, Memory, Disk, Log 등의 일일점검과 파일 권한, 계정 및 서비스 설정 등의 보안점검 결과를 동일한 실행 흐름에서 처리할 수 있도록 구성했습니다.

## 공개 코드 범위

현재 저장소에는 K뱅크 전체 자동화 구축 범위 중 서버 일일점검과 보안점검 관련 일부 코드만 포함되어 있습니다.

고객사 보안 정책에 따라 전체 구축 코드는 공개하지 않습니다.
