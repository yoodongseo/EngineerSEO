# 금융권 망분리 환경 서버 점검 자동화

**"수동 점검의 늪에서 벗어나기 위한 첫걸음"**

이 코드는 K뱅크 망분리 환경에서 수십 대의 서버 상태(CPU, Memory, Disk, Log, 권한 등)를 일일 점검하기 위해 작성했던 초기 Ansible 자동화 코드입니다.

## 🤔 치열했던 기술적 고민

- **환경적 제약:** 외부망과 단절된 금융권 특성상, 의존성 패키지를 쉽게 다운받을 수 없어 제한된 환경 내에서 Ansible 모듈만으로 승부를 봐야 했습니다.
- **파편화된 점검 로직:** 장비별로 다르게 떨어지는 결과값을 처리하기 위해 필터(`filter/`)와 플레이북 로직이 점점 무거워지고 복잡해지는 문제가 있었습니다. 
- **공통화의 시도:** Telnet이나 SSH 접속 방식이 섞여 있는 환경을 극복하기 위해 공통 접속 모듈(`module_utils/fap_common_custom.py`)을 억지로라도 하나로 빼내어 관리하려고 시도했던 흔적이 남아있습니다.

## 🚀 무엇을 배웠는가?
이 프로젝트를 통해 "플레이북에 로직을 너무 많이 담으면 대상 서버가 늘어날 때마다 유지보수 지옥이 열린다"는 사실을 뼈저리게 배웠습니다. 점검 명세서와 실행 로직을 근본적으로 분리해야겠다는 아이디어를 얻게 된 소중한 과도기적 프로젝트입니다.
