# 서부발전 인프라 점검 POC

서부발전 환경의 서버·네트워크·보안장비를 대상으로 인프라 점검 자동화를 검증한 POC 코드입니다.

기존 인프라 점검 코드를 대상 환경에 맞게 수정하고, 장비별 접속 방식과 명령어·출력 차이를 반영해 점검 결과를 공통 형태로 처리하도록 구성했습니다.

## 주요 구현

- Linux·Windows 서버 점검
- 네트워크·보안장비 점검
- Piolink·Axgate SSH 기반 점검
- Secui 방화벽 REST API 연계
- 장비별 점검 결과 파싱 및 데이터 구조화
- 이기종 장비의 점검 결과를 공통 형식으로 처리

## 구현 방식

대상 장비와 Vendor에 따라 점검 명령과 실행 방식을 분리하고, 장비별로 서로 다른 출력 결과를 Python Filter와 Parser를 통해 가공했습니다.

Piolink와 Axgate 장비는 SSH 기반으로 점검 명령을 실행하고 결과를 수집하도록 구성했습니다.

Secui 방화벽은 REST API 응답을 받아 점검 결과 처리 구조에 맞게 변환해 기존 자동화 흐름과 연계했습니다.

## 공개 코드 범위

현재 저장소에는 서부발전 POC에서 사용한 인프라 점검 관련 Ansible Playbook과 Python Filter·Parser 코드가 포함되어 있습니다.

실제 고객 환경의 접속 정보와 운영 설정은 제외하고, 자동화 구현 구조를 확인할 수 있는 코드만 정리했습니다.
