# 서울시데이터센터 자동화 코드

| 영역 | 코드 |
| --- | --- |
| Linux 운영 자동화 | [LV/VG 관리](시범사업/리눅스_LV생성/), [일일점검](시범사업/리눅스_일일점검/), [자원현황](시범사업/리눅스_자원현황/), [업데이트](시범사업/리눅스_마이너업데이트/), [파일 배포](시범사업/리눅스_파일배포/) |
| Windows 운영 자동화 | [일일점검](시범사업/윈도우_일일점검/), [자원현황](시범사업/윈도우_자원현황/), [보안 패치](시범사업/윈도우_보안패치/) |
| 네트워크 및 보안장비 | [네트워크 일일점검](시범사업/네트워크_일일점검/), [네트워크 자원현황](시범사업/네트워크_자원현황/), [보안장비 일일점검](시범사업/보안장비_일일점검/) |
| 미들웨어 및 서버 점검 | [Tomcat 관리](시범사업/미들웨어_톰캣관리/), [Tomcat 운영관리](시범사업/미들웨어_톰캣운영관리/), [서버 예방점검](시범사업/서버_예방점검/) |
