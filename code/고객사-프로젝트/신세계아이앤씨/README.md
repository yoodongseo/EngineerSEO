# 신세계아이앤씨 자동화 코드

신세계아이앤씨 프로젝트의 자동화 구현 코드입니다. 기능별 코드는 아래 상위 경로에서 확인할 수 있습니다.

## 주요 구현 영역

| 영역 | 내용 | 코드 |
| --- | --- | --- |
| 미들웨어 관리 | Tomcat 시작 및 종료 작업 | [미들웨어관리](미들웨어관리/) |
| 솔루션 프로비저닝 | 솔루션 설치 관련 구현 | [솔루션프로비저닝](솔루션프로비저닝/) |
| 운영 자동화 | 취약점점검, 시스템 구성점검, Sysinfo 수집, OS 설정 작업 | [운영자동화](운영자동화/) |
| 재해복구 자동화 | 단계별 전환 및 복구 작업 | [재해복구자동화](재해복구자동화/) |

## 재해복구 자동화 구조

`재해복구자동화/`에는 `DR_01_DR동기화중지`부터 `DR_07_DR동기화수행`까지 단계별 구현이 있습니다.

## 구조

```text
신세계아이앤씨/
├── README.md
├── 미들웨어관리/
├── 솔루션프로비저닝/
├── 운영자동화/
└── 재해복구자동화/
```
